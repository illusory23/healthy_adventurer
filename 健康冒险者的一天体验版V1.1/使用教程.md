# 《健康的冒险者的一天》· 体验版 V1.1 使用教程

> 一个把**健康打卡**变成奇幻冒险的小游戏：现实中好好睡觉、坚持运动、按时吃饭，游戏里的冒险者就会更强——委托成功率更高、奖励更多。游戏会悄悄"盯着"你的作息，请善待自己 :)

---

## 一、运行要求

- Windows 电脑
- 安装 [Python 3](https://www.python.org/downloads/)（免费）
  - ⚠️ 安装时**务必勾选**第一屏底部的 **"Add Python to PATH"**，否则后面会报错

## 二、启动步骤（三步）

**第 1 步｜装一次依赖**
按 `Win + R` 输入 `cmd` 回车，在黑色命令窗口里粘贴执行：

```
pip install flask
```

下载慢的话用国内镜像：

```
pip install flask -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**第 2 步｜启动游戏**
双击文件夹里的 **run.bat** —— 会弹出一个小黑窗，显示服务启动信息。
（这个窗口就是游戏服务器，**玩的时候别关它**）

**第 3 步｜打开游戏**
浏览器访问：**http://localhost:5899**

首次进入输入你的冒险者之名，即可开始。以后每次：双击 run.bat → 打开上面的网址，两步开玩。

## 三、存档说明

- 进度自动保存在本文件夹的 `data\adventurer.db` 里，**关窗口不丢档**。
- **备份 / 换电脑**：把整个文件夹拷走即可。
- **导出 / 导入**：「冒险者信息 → 存档」里可导出快照（JSON 文件）、也可导入 JSON 存档（导入会覆盖当前账号进度，建议先导出一份备份）。

## 四、手机也想玩？（同一 WiFi）

1. 电脑上双击 run.bat（保持小黑窗开着，电脑不要睡眠）。
2. 看小黑窗里打印的地址（形如 `http://192.168.x.x:5899`），手机连**同一 WiFi**，浏览器输入这个地址。
3. 手机首次访问会让你输入**访问口令**——口令就写在文件夹里的 `access_key.txt` 文件中（首次启动自动生成），输入一次后长期记住。
4. 手机与电脑**各有独立账号**（互不影响）；若想在手机上继续电脑的进度：在电脑上打开「冒险者信息 → 账号」，查看 8 位**接入码**，再到手机的同页输入即可绑定。

> 如果你在外面（手机用流量、连的不是家里 WiFi）也想玩 → 看下一节 👇

## 五、手机不在家 / 异地也能玩（内网穿透）

手机用流量、或在外面别的 WiFi 时，与电脑**不在同一网络**，直接输 `192.168.x.x` 那种地址是连不上的。这时需要用**内网穿透**把电脑上的游戏"穿"到公网，让手机在任何网络下都能连上。

推荐 **樱花内网穿透（SakuraFrp）**，免费可用：

1. 到 [SakuraFrp 官网](https://www.natfrp.com/) 注册账号，下载 **SakuraFrp 启动器**（Windows 版）并登录。
2. 在启动器里「隧道」→「创建隧道」：
   - 隧道类型：**HTTP(S)**（自带 HTTPS 证书，手机打开无安全警告）
   - 本地地址：`127.0.0.1`
   - 本地端口：`5899`
   - 节点：选延迟低的
3. 创建后点「启动」，会得到一个访问网址，形如 `https://xxxxxx.natfrp.com`。
4. 手机在**任何网络**下打开这个网址即可玩——首次要输访问口令（见下一节说明），输一次后记住 90 天。

**注意事项**

- **三件套缺一不可**：电脑开机且不睡眠、run.bat 小黑窗开着、樱花启动器里隧道"运行中"——电脑一关/睡，手机就断了（建议把 Windows 电源设置里的"睡眠"改为**从不**）。
- 免费隧道有带宽限额，但打卡游戏流量极小，完全够用。
- 这个网址相当于把你家游戏暴露在公网上——好在有**口令门保护**（见下），但**网址和口令都别随便发给别人**。
- 想一键同启（可选）：用记事本打开 run.bat，在注释区找到 `REM start "SakuraFrp" ...` 那一行，删掉行首的 `REM`，并把路径改成你电脑上 SakuraFrp 启动器的实际位置。

> 同类的其它工具（cpolar、花生壳等）也可以，思路完全一致：把本机 `127.0.0.1:5899` 映射成一个公网网址即可。

### 访问口令是什么？

进入游戏（局域网或穿透访问）首次会让你输**访问口令**——它是自动生成的，就在本文件夹的 `access_key.txt` 文件里（首次启动游戏后出现）。
- 输一次即可，手机自动记住 90 天，之后无感。
- 电脑本机 `http://localhost:5899` 永远免输。

## 六、常见问题

| 现象 | 解决办法 |
|---|---|
| 提示 `'python' 不是内部或外部命令` | Python 安装时没勾选 "Add Python to PATH"，重装并勾选 |
| `pip install flask` 慢或失败 | 用上文国内镜像命令 |
| 双击 run.bat 窗口一闪而过 | 在 cmd 里手动运行 `python app.py`，按提示看缺什么（多半是 flask 没装成功） |
| 浏览器打不开游戏 | 确认小黑窗还开着；仍不行就重启电脑（端口可能被占用） |
| 手机连不上（同一 WiFi） | 确认：电脑没睡眠、手机与电脑在同一 WiFi、地址输的是小黑窗里那串 |
| 手机连不上（异地 / 流量） | 检查三件套：① 电脑开机不睡眠 ② run.bat 小黑窗开着 ③ 樱花启动器里隧道"运行中" |
| 提示口令不正确 | 口令**区分大小写**，打开 `access_key.txt` 核对原文（注意别把行尾空格复制进去） |

## 七、游戏小贴士（无剧透）

- **游戏跟着现实走**：好好睡觉、按时吃饭、坚持运动——冒险者会实实在在变强（委托更容易成功、奖励更丰厚）。
- **伙伴系统**：旅途中会遇到愿意同行的小家伙。宠物有**品阶之分**——从随处可见的小家伙，到深藏于难关之后的传奇伙伴；越难得的伙伴，成长后的助力越强。
- **养成方式**：宠物各有口味，喂它喜欢的食物成长更快；喂稀有的特殊材料，还能积攒"变异"的可能。个别伙伴的成长与你的**现实习惯**绑定——怎么养，游戏里会告诉你。
- **委托**：等级越高，风险越大、回报越丰厚；接取高级委托前记得备好任务准备物（接取会消耗，炼金台可合成）。
- **图鉴**：遇到过的材料、装备、料理、道具与伙伴都会被记录下来——喜欢收集的话，可以慢慢把它填满。

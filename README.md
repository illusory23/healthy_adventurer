# 《健康的冒险者的一天》

> 一套用游戏系统激励健康作息的个人养成规则
> **版本 v1.61h · 完整版**

---

## 核心原则

1. **委托是游戏世界冒险，统一池随机抽取**；健康任务是现实习惯，独立结算
2. **健康只影响委托成功率**，不绑定委托内容——没做运动也能打怪，只是会打输
3. **高级委托报酬更高，但基础成功率更低，硬上限收紧**
4. **健康是变强的主要途径**——这一条在终盘的世界级事件里权重最高

## 快速上手（第一天怎么玩）

### 1. 建角色

- 等级 **Lv1**，精力上限 **60**，每日上限 **4 个**委托（受精力所限，实际约 3.9 个）
- 公会 **F 级**，声望 0，贡献 0
- 健康评分从今天开始记录，满分 100

### 2. 当日流程

```
早上起床  →  打卡「7:40 前起床」(+15)
         →  08:00 刷新，抽 1 选 1 接一个 Lv1 委托
         →  按现实耗时完成，完成即掷 1d100（Lv1 必成功）
         →  12:00 / 18:00 / 21:00 还有 3 次刷新，各可再接 1 个
白天      →  喝水、午休、运动、三餐、久坐起身、阅读，随时打卡
晚上 21:00 →  最后一个刷新点（接取窗口放宽至 23:30）
     23:30 →  打卡「23:30 前入睡」(+20)
         →  健康分定档（次日 06:00 跨天时结算，给声望/贡献/活力点）
```

### 3. 健康分怎么算

| 项目 | 分值 |
|---|---:|
| 23:30 前入睡 | 20 |
| 7:40 前起床 | 15 |
| 午休 30 分钟 | 5 |
| 喝水 1.5L | 10 |
| 运动 20 分钟及以上 | 10 |
| 完整吃三餐 | 15 |
| 睡前不刷手机 30 分钟 | 5 |
| 久坐起身（最多 4 次） | +2 / 次 |
| 阅读 30 分钟及以上（最多 2 次） | **+6 / 次** |
| **每日合计** | **100** |

### 4. 健康分有什么用

- **当天**：直接加成「进行中委托」的成功率（每 10 分 = 2 个百分点）
- **当天结算**：直接给声望（90+ 给 8 点）、贡献、活力点
- **次日**：区间奖励（报酬加成、精力加减）
- **长期**：周打卡、月打卡、成就

### 5. 第一条目标线

**两条进度线并行推进，声望线更慢。**

| 里程碑 | 线 | 条件 | 大致时间 |
|---|---|---|---|
| 公会 E 级 | 声望 | 100 声望 → **解锁公会商店** | 第 5 天 |
| **Lv2** | 经验 | 60 经验 → **解锁公会系统 + 交易所（卖出材料）** | 第 6 天 |
| 解锁探索 | — | **Lv2 + 完成 12 次 Lv2 委托**（v1.60） | 第 6~10 天 |
| 公会 D 级 | 声望 | 400 声望 → **技能树 + 贡献商店开放** | 第 12 天 |
| 公会 C 级 | 声望 | 850 声望 → 冥念护符 I、图书馆、**探索·深层一阶（Lv3+C）** | 第 22 天 |
| **Lv3** | 经验 | 500 经验 | 第 26 天 |
| 公会 B 级 | 声望 | 1,200 声望 → 冥念护符 II、精英委托重掷券 | 第 30 天 |
| 公会 A 级 | 声望 | 2,200 声望 → **传奇事件门槛**、冥念护符 III、**探索·深层二阶（Lv4+A）** | 第 47 天 |
| **Lv4** | 经验 | 3,000 经验 | 第 50 天 |
| **Lv5** | 经验 | 8,000 经验 | 第 69 天 |
| 传奇资格 | 经验 | 30,000 经验 | 第 98 天 |
| **公会 S 级** | 声望 | 6,500 声望 → 铂金商店、冥念护符 IV、**探索·深层终段（Lv5+S）** | **第 100 天** |
| 公会 W 级 | 声望 | 9,000 声望 → 称号「**世界行者**」· 每日上限 +1 | 第 128 天 |
| 公会 H 级 | 声望 | 13,000 声望 → 称号「**英雄**」· 同时进行 +1 | 第 172 天 |
| **公会 P 级** | 声望 | **18,000 声望 → 称号「至尊」· 满级** | **第 228 天** |

> **终局瓶颈是声望，不是等级**——经验线在第 98 天就到顶了，但公会要到第 100 天才够 S 级。
>
> **S 之上还有 W / H / P 三级**：它们不解锁新玩法，而是提供**突破系统性上限的特权**（接取上限、同时进行上限、传奇事件频次、精力上限）。这是给"已经打完终局"的玩家准备的长期追求。

## 设计要点（为什么这么做）

| 设计 | 目的 |
|---|---|
| 健康不绑定委托内容 | 避免"没做运动就不能打怪"的强制感与挫败 |
| 健康 0→100 恒定值 +20pp | 让健康投入在任何等级都同等有效，不会后期失效 |
| 传奇事件健康权重 ×2.5 | 让终盘目标仍然由作息决定，而不是装备 |
| 次日生效的区间奖励 | 避免即时奖励造成的刷分冲动 |
| 断连保护（周 1 次 / 月 3 次） | 防止"一次失误 = 全盘归零"的破罐效应 |
| 精力是接取数量的唯一约束 | 每日上限固定 4 个（= 刷新次数），但各等级都接不满，必须靠成长系统补足 |
| 冥念护符 / 创世之印不计入 E | 终极目标应凌驾于常规装备体系之上（唯二例外，v1.41 H6 后并列） |
| 成就饰品独立槽位 | 局外荣誉不干扰局内配装平衡 |
